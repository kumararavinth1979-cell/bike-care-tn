# Bike Care TN

A simple static website for searching 50+ motorcycle models and viewing general maintenance guidance.

## Run locally
Open `index.html` in a browser, or use any static web server.

## Deploy with GitHub + Render
1. Create a new GitHub repository, e.g. `bike-care-tn`.
2. Upload every file/folder from this project.
3. On Render, create **New → Static Site** and connect the GitHub repository.
4. Build command: leave empty.
5. Publish directory: `.`
6. Deploy.

## Important
The included visuals are clearly marked placeholders so you do not accidentally use copyrighted manufacturer photos without permission. Replace `assets/bike-*.svg` with photos you are licensed/allowed to use, keeping the same filenames, or update `image` paths in `bikes.json`.

Maintenance intervals are general guidance, not a substitute for the exact owner's manual. Service intervals can differ by model year, market and riding conditions. Verify exact schedules against the manufacturer's manual before presenting them as official.

The model list is intended as a Tamil Nadu-focused starter catalogue; it is not a claim that these are literally every two-wheeler available in the state.
